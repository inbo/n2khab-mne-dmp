# MNE DMP: Data Management Plan of the Monitoring Programme for the Natural Environment

This repository is used for the collaborative work on the documentation of data management practices on the MNE project.

Besides general notes and helper files, each new published version of the DMP can be found in a separate subfolder.
We use [Quarto](https://quarto.org) documents, in particular [Quarto Books](https://quarto.org/docs/books/), to prepare the DMP in different document formats.


The latest published version of this DMP can be found here:

+ <https://www.vlaanderen.be/inbo/en-GB/publications/data-management-plan-for-mnm>
+ <https://pureportal.inbo.be/en/publications/data-management-plan-for-mnmmne-version-1/projects/>


This repository will contain changes and drafts deviating from prior official publications.
Please keep in mind that those changes are unofficial: they are work in progress, open suggestions to be discussed among the authors, potentially unreviewed, and subject to change.


# Contribution

Contribution to this DMP is generally reserved for INBO staff working on or supporting the MNE project.
However, we appreciate any comments and questions on the manuscript. 
Errata are welcome to be reported via github issues.
